## Deskripsi
Repositori ini berisi hasil pengerjaan Praktikum 5 tentang JavaScript. Praktikum ini bertujuan untuk memahami dasar-dasar JavaScript dan penerapannya pada halaman web menggunakan HTML.

## Daftar Praktikum

### Latihan
1. **Latihan 1:** Menampilkan teks menggunakan JavaScript.
2. **Latihan 2:** Menggunakan `alert()` dan `prompt()`.
3. **Latihan 3:** Operasi aritmetika menggunakan fungsi.
4. **Latihan 4:** Percabangan `if-else`.
5. **Latihan 5:** Percabangan `switch`.
6. **Latihan 6:** Memeriksa bilangan genap atau ganjil melalui form.
7. **Latihan 7:** Mengubah warna latar belakang halaman.
8. **Latihan 8:** Menghitung total harga menu menggunakan checkbox.

### Mini Project
Membuat program penghitung nilai akhir mahasiswa berdasarkan nilai tugas, UTS, dan UAS, kemudian menentukan predikat dan status kelulusan.

### Eksperimen Mandiri
1. Memodifikasi operasi aritmetika agar menerima dua bilangan dari `prompt()`.
2. Menampilkan tabel perkalian 7 menggunakan perulangan.
3. Membuat fungsi `cekGenap(angka)` untuk memeriksa bilangan genap.
4. Menambahkan validasi agar form tidak dapat dikirim jika kolom wajib kosong.
5. Menambahkan pilihan menu dan harga pada program checkbox.
6. Membuat tombol untuk menyembunyikan dan menampilkan elemen HTML.

## Cara Menjalankan
1. Unduh atau clone repositori ini.
2. Buka file HTML yang ingin dijalankan menggunakan browser.
3. Ikuti petunjuk pada halaman dan coba fitur yang tersedia.
